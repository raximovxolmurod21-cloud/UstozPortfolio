# UstozPortfolio v12 — o'zgarishlar

## 1. Dinamik OTMlar
`institutions` jadvali qo'shildi. Dastlabki 4 OTM avtomatik kiritiladi. Admin istalgancha OTM qo'shishi mumkin.

## 2. Cheklanmagan respondentlar
OTM uchun 60 va EG/NG uchun 30 kishilik limitlar olib tashlandi. Tajriba-sinovning haqiqiy tanlanma hajmi endi admin va tadqiqot dizayniga bog'liq.

## 3. Admin boshqaruvi
- OTM qo'shish
- OTMni faol ro'yxatdan yashirish
- Respondentlar bo'yicha dinamik OTM filtri
- EG/NG guruhini admin biriktirishi

## 4. Markazlashgan baza
Respondent registration, login, state, PRE/POST diagnostika va audit ma'lumotlari server bazasida saqlanadi.

## 5. Keyingi texnik bosqich
VPS + PostgreSQL + HTTPS + domen + backup + production security.
