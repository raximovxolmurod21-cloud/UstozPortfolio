## v4 — Dissertatsiyaga mos diagnostika
Diagnostika moduli dissertatsiyaning 4.2-§, 20-jadvalidagi uch komponent va to‘rt darajali mezonlarga tayangan: **kognitiv**, **motivatsiyali-aksiologik**, **praksiologik**; **reproduktiv**, **variativ**, **qisman izlanuvchi**, **mobillik**. Aralash ta’limga oid 18 savol ushbu mezonlarni platformada operatsionlashtirish uchun alohida ishlab chiqilgan. Savollar manbadagi eski obyektni aynan ko‘chirmaydi.
